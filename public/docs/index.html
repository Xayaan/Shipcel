Shipcel docs

Everything Shipcel does, step by step: from your first deploy to running Shipcel yourself. Shipcel puts your apps in your own Cloudflare account, so each guide also says what happens there.

Get started

Getting startedShipcel deploys and manages apps in your own Cloudflare account, the way you would on Vercel or Netlify, without writing infrastructure code.The shipcel CLIThe shipcel command sets up, builds and deploys your site or app to your own Cloudflare account, and manages your projects from a terminal or CI.

Deploy

Deploy from GitHubConnect a repository and every push deploys.Deploy from GitLab, Bitbucket or GiteaA repository on GitLab, Bitbucket, Gitea or Forgejo deploys the way a GitHub repository does: every push builds in that host's own CI, which runs shipcel deploy.Deploy without GitDeploy a site or an app straight from your computer to your Cloudflare account: run shipcel in its folder, drop a built folder on the dashboard, or ask your AI agent.Starter kitsA starter kit is a complete new app, generated for your project, in exactly the shape Shipcel's GitHub deployments expect.Previews and rollbacksTry a change at its own address before it reaches production, and put production back in one step when something goes wrong.

Build your app

Environment variablesYour app gets configuration two ways: secrets, which the running app reads, and build variables, which a GitHub project's build reads.DomainsEvery app has a free address on Cloudflare's workers.dev, and you can add your own domain with a certificate in a few minutes.Databases and storageYour app's data lives in your Cloudflare account: SQL in D1, files in R2, and key-value data in KV.Sign-in and realtimeShipcel can run a sign-in and realtime service for your app, in your own Cloudflare account: a Worker, a D1 database for its users and a Durable Object class for channels.Logs and analyticsSee how your app is doing: requests, errors, response times and CPU time from Cloudflare's analytics, HTTP status codes and recent requests and exceptions from Workers Logs, and notifications when a deploy or a health check fails.

Workspace

Teams and tokensWork with other people in a shared workspace, give each the access they need, and let the CLI, scripts and AI agents act for you with API tokens.AI agentsLet your own AI agent deploy and manage your apps: Claude Code, Codex, Cursor or any agent that speaks the Model Context Protocol (MCP).Free-only and billingShipcel's Free plan costs nothing, and your apps use Cloudflare's free allowance in your own account.

Run Shipcel

Self-hostingShipcel is a Cloudflare Worker with a D1 database.Add a starter kitThe App catalog is the kits/ folder in Shipcel's repository: one TypeScript file per starter kit.TroubleshootingWhat the most common messages mean and what to do about them.
