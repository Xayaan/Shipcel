What Shipcel does today

Built means implemented, tested and run on live Cloudflare accounts. Beta rests on a Cloudflare feature still in beta, or hasn’t run against a live account yet. Not yet means exactly that.

Start your way

Built

Your own AI agent

An MCP server for Claude Code, Codex, Cursor and other agents: create projects, deploy files, publish, roll back, set secrets. Agents sign in with an API token you can revoke.

Built

Deploys from GitHub

Every push builds with GitHub Actions and deploys to your account: the production branch to production, other branches as previews.

Built

The shipcel command

shipcel from a terminal or CI: signs in through the browser (or a token), recognises Vite, Create React App, Vue CLI, Astro, Gatsby, Docusaurus, VitePress, Eleventy, Hugo, Jekyll and more, builds on your computer and uploads only changed files. A new app’s first deploy goes to production; later ones are previews until you say otherwise.

Beta

Apps with code, from your terminal

shipcel also deploys Next.js, SvelteKit, React Router, Nuxt, Angular, TanStack Start, Qwik City, Astro with server output and any Worker with a Wrangler configuration, with its bindings, adding the framework’s Cloudflare adapter when it has none. Run live for React Router, Next.js, SvelteKit and a Worker with D1, KV and a Durable Object; the others in Cloudflare’s local runtime.

Built

Drag and drop

Drop a built folder in the dashboard; a new app stays unpublished until you publish it.

Built

Starter kits and imports

Fourteen starter kits (React, Vue, Hono, a Postgres API on Hyperdrive, a static site, a JavaScript Worker, Astro, SvelteKit, Next.js, Python, a container app, Umami and n8n as services, and WordPress, experimental), and imports of existing repositories for the same frameworks and for Docker containers (containers need Workers Paid).

Built

Workers AI, Durable Objects and more

Imports can use Workers AI, SQLite-backed Durable Objects, browser rendering, Images, variables, Smart Placement and cron schedules, all on the free plan.

Previews and releases

Beta

A preview for every branch and pull request

Cloudflare Worker Previews, with the address commented on the pull request. Previews bind staging copies of your databases, namespaces and buckets, never production data.

Built

One-click rollback

Send all traffic back to an earlier version from Manage, the CLI or your agent.

Built

Traffic splitting

Give a new version a share of traffic first; Shipcel checks that version before you send it everything.

Built

Health checks and recovery

A homepage check after every deploy, and interrupted steps checked against Cloudflare before anything is repeated.

Built

Free addresses and custom domains

your-app.your-name.workers.dev for every app, and your own domains attached in a few clicks.

Built

Protected previews

Ask reviewers to sign in before they open preview addresses, with Cloudflare Access in your account. Zero Trust’s free plan covers 50 people; Cloudflare asks for a payment method when you set it up.

Data

Built

SQL databases, files and key-value data

D1, R2 and KV created in your account after you review them.

Built

Migrations, exports and point-in-time restore

Reviewed migrations with a restore point first, SQL exports, and restore to any moment in Time Travel’s window.

Built

Scheduled backups

Daily or weekly copies of a D1 database in an R2 bucket of your account, each downloadable.

Built

Table browser and SQL console

Page through your D1 tables and run SQL; queries that change data are confirmed, with a restore point recorded before each one.

Built

File and key-value browser

Browse R2 folders and KV keys, open and edit text values, upload files up to 25 MB, download and delete. Changes are confirmed and recorded without their contents.

Built

Data API and row-level security

REST over the D1 tables you open, read and changed by everyone, signed-in users or each row’s owner, with each change on realtime.

Sign-in and realtime

Built

Sign-in for your users

Passkeys, GitHub, Google, email links and optional passwords, as standard OpenID Connect, in your account with no monthly user limit. Email and passwords need Workers Paid.

Built

Realtime channels

Broadcast and presence on Durable Objects, with listeners free and idle connections hibernating.

Not yet

Phone sign-in

Codes by text message need an SMS service, which Shipcel doesn’t set up.

Operate

Built

Runtime secrets

Set and remove secrets; values go only to Cloudflare and are never shown again.

Built

Build variables

Variables your build command reads, set separately for production and branch preview builds; secret values go only to Cloudflare.

Built

Shared variables

One secret set on several projects at once; the value goes only to Cloudflare.

Built

Deploy notifications

A webhook (Slack, Discord or any HTTPS endpoint), a Telegram chat through your own bot, or a confirmed email address, when a deploy goes live or fails or a health check fails.

Beta

Firewall for your domains

Cloudflare’s DDoS protection covers every app. For an app with a custom domain, Manage → Security and shipcel security turn on Cloudflare’s Free Managed Ruleset, Bot Fight Mode, AI crawler blocking and Under Attack mode, and add rules by country, IP or path and a rate limit, all free. Tested against a stand-in for Cloudflare, not yet a live zone.

Built

Free-only mode

On by default: Shipcel creates nothing in a project that Cloudflare can bill for.

Beta

Budget guard

Every five minutes Shipcel estimates each app’s cost beyond what Cloudflare includes, from Cloudflare’s analytics, and alerts at 50%, 80% and over its budget ($0 by default). An owner can have it pause an app over budget: production answers 503 and schedules stop, data kept, until resumed. Tested against a stand-in for Cloudflare, not yet a live account.

Built

API tokens

For the CLI, agents and scripts; shown once, revocable, and unable to change billing or connections.

Built

Cron schedules

Run your Worker on a schedule: listed in your Wrangler configuration, or set in Manage → Schedules.

Built

Analytics and logs

Requests, errors and CPU time by hour, and recent log lines and errors from Workers Logs, in Manage.

Not yet

Queues and Workflows in Shipcel

Available in Cloudflare’s dashboard for your account; not yet in Shipcel’s imports or dashboard.

Built

Teams and roles

Shared workspaces with owners, developers and viewers, joined by invitation links; no seat fees.

Not yet

Forms and image optimization

Not built in; use a form service or library, and Cloudflare Images separately.
