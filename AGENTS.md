# Cloudcel project instructions

Read `HANDOFF.md` before working. It records the user’s full product scope, verified features, in-progress changes, missing configuration, and exact next steps. Update it before handing off or ending a substantial work session.

Use relevant skills from the enabled `ecc@ecc` plugin automatically when the task matches their descriptions. Read each selected `SKILL.md` before applying it; combine complementary skills when useful. Follow current user instructions and do not infer unrelated external authorization from a skill.

Keep fixture evidence distinct from live deployment evidence. Never claim broad runtime support from a catalog entry alone. Keep provider credentials in ignored local configuration/provider secret storage, never in chat, browser responses, logs, or exports.
